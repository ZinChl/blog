刚拿到 Azure for Students，花了一晚上把它的规则摸了一遍。结论是：**能用的比想象中多，但有三条限制决定了你怎么用它**。

## 你实际拿到的是什么

- **$100 额度**，12 个月内有效
- **每年可以续**，只要学籍仍然有效
- **55+ 项免费服务**，其中一部分是永久免费的
- 不需要信用卡

因为不用信用卡，这个订阅带**支出限制（spending limit）**。好处是你不可能被意外扣钱；代价是额度用完后**订阅会被直接禁用**，而不是自动转成按量付费。想继续用必须联系支持升级。

## 免费额度里最值钱的几项

| 服务 | 每月免费额度 |
| --- | --- |
| 虚拟机 Linux / Windows | 750 小时（B2ats v2 或 B2pts v2）|
| MySQL / PostgreSQL | 各 750 小时（B1MS） |
| Blob 存储 | 5 GB |
| Azure 文件存储 | 100 GB |
| 出站流量 | 15 GB |
| 认知服务 | 视觉 5000 次 / 人脸 3 万次 |

750 小时的意思是一台机器可以 **24 小时不间断开着**（一个月才 730 小时左右）。对个人项目来说，这基本等于「免费送你一台永远在线的服务器」。

> 注意机型。只有 `B2ats v2`（AMD）和 `B2pts v2`（Arm）这两档算在免费额度里，开成别的型号会从 $100 里扣钱。

## 额度买不了什么

官方条款里明确排除的项目：

- Azure 支持计划
- Azure DevOps
- Visual Studio 订阅
- ExpressRoute
- Marketplace 上的第三方产品
- 单独授权的产品（比如 Entra ID Premium）

## 两条容易踩的坑

**第一，免费额度按月重置，超量从额度扣。** 比如出站流量超过 15 GB 的部分，是按量计费的。

**第二，虚拟机「停止」不等于停止计费。** 必须做「解除分配（Deallocate）」才会真正停止计算计费 —— 否则磁盘和公网 IP 照样扣钱。这是新手最容易中招的地方。

## 那 GPU 呢

我查了一下订阅里的 SKU 列表，**GPU 机型全部标记为不可用**。T4、A100、H100 都是 `NotAvailableForSubscription`。学生订阅默认没有 GPU 配额，需要单独申请，而且通常批不下来。

想在课程里跑深度学习，还是老老实实用 Colab 或者学校自己的集群。

## 实际怎么用

按我的需求，最合理的搭配是：

1. **一台常驻的小虚拟机** —— 跑 Docker、自建服务或者挂机器人，走 750 小时免费额度
2. **静态站点托管** —— 就是这个博客，Static Web Apps 免费层，还自带 CDN 和 HTTPS
3. **数据库** —— MySQL 或 PostgreSQL 的 750 小时免费实例，足够个人项目

这套组合下来，一年下来账单是 **$0**，$100 额度根本用不上。
